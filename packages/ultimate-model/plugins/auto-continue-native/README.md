# 可选有界自动接续兼容插件

新模式不叠加本插件，使用宿主Goal/轮次机制。该源码为本机既有安装的修复副本，不声称替换了已加载进程中的旧模块。

- 尊重实际readMax预算，不强行拉到五次；活跃且armed的Goal拥有接续时不重复排队。
- AbortError、用户取消/拒绝、认证/配额/协议等不可恢复错误撤销pending与timer；不把取消当需要再尝试。
- 每次撤销递增generation；即使已经取出的旧回调后来被调用，也不能在用户新消息、取消、释放后复活任务。
- agent disposed清理；真正人类消息可重置失败链，错误输入不自动刷新预算。followup须仍是同一空闲、存活的agent。
- 重试不是零成本，不修改模型/凭据/宿主服务。日志是本机诊断，不是外传记忆。

回归覆盖上限、取消、取消撤销、过期回调与释放。没有达到预算不等于必须凑数；没有可安全继续项就报告具体缺口。
