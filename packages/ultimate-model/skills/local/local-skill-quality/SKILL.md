# DSH 技能与能力包质量

目标是让相关任务能找到、读到并实际使用可用能力，同时保留接收端定制。先解决本次目标涉及的缺口；文件数量和技能数量不作为质量指标。

## 先确认现有入口

核对当前 DSH home、Profile、所选预设和任务写域，不从打包者路径或旧报告推断本机状态。只读审查不安装、启用、移动或更新能力。

- 已列名且与当前任务相关的技能，使用当前 `skill` 工具加载；已有真实路径时可读取该 `SKILL.md`。明确选用或已授权任务必需的调用直接执行，不再询问同一个选择。
- 未知领域先使用当前可用的 `jizhi_skill_search`，命中后读正文。缺该工具、离线或诊断来源时，使用当前 home 的 `skill-load.mjs`；已有一次有效搜索时不叠加相同查询。
- 搜索返回名称、描述、来源和路径只表示发现元数据。读过正文才算载入；工具可见、正文存在也不证明执行成功。发现同名多源时保留各路径，先核实当前宿主实际选择，不以搜索排序代替优先级。
- 相关的已安装可选能力，只有尚需用户决定的取舍才询问是否使用；只读加载无需额外确认，外部写入、费用或敏感访问仍按当前授权处理。忽略被拒绝、否定或仅作引用/讨论的选项，不从沉默或超时生成同意。

## 包与本机逐项比较

比较单位是具体能力及其运行依赖，而非整个目录覆盖。先核对包来源、版本或文件 hash，再按以下证据决定：

| 现场证据 | 处理 |
| --- | --- |
| 当前内容与本次批准版本一致 | `KEEP`，复用当前入口 |
| 当前内容与可追溯的可信旧版本完全一致，且本轮授权覆盖更新 | 可更新；备份、安装后读回并保留版本关联 |
| 有本地修改/额外文件、多源同名、旧来源缺失或读取不明 | `REVIEW_UPDATE`，保留原件，列出差异；未知不能当作缺失或未改 |
| 确认未安装，且为通用或用户明确偏好能力 | `ASK_INSTALL`，在实际安装前取得当前选择 |
| 用户已明确选择本次安装的能力 | 在授权内安装所选项及必要技术依赖，不重复确认；不把本次选择写成长期偏好 |
| 确认未安装、专门且与当前任务/偏好无关 | `SKIP` |

复制冲突的裁决同样约束后续路径重写、索引生成和配置物化；不能前面保留了旧文件，后面又改写它。更新比较要区分原包 source hash 与接收端完成路径适配后的部署 hash。已有定制不能因 `-Force`、新版本号或一份新清单就被认定可覆盖。

## 补齐依赖与能力承接

为本次所选能力列明：技能正文、被点名的必要技能、技能自带/共享脚本、脚本的包内模块、运行时包和宿主注册入口。复用已安装的同域能力，避免为相同机制再建一套实现。

现成脚本位于当前 home 的 scripts 目录，调用前确认文件及当前版本：

| 入口 | 用途与结果边界 |
| --- | --- |
| `skill-load.mjs --home <已核实home> <关键词>` | 实时只读查找；退出 0 为命中、3 为当前根未命中、2 为输入/元数据/IO 错误。无命中不代表宿主全量目录没有能力 |
| `build-skills-index.mjs --home <已核实home> --check` | 只读检查当前扫描根与索引是否一致；漂移不是自动重建授权，索引也不是宿主装载清单 |
| `audit-skill-runtime-deps.mjs --check` | 在该子进程绑定已核实的 `DSH_HOME` 后检查技能所引脚本。先读本版覆盖范围；只查正文路径时，另查代码块、点名技能及脚本的递归模块依赖 |

依赖闭包缺失、循环、越界或来源不明时，先报告具体条目，不能以现有静态审计绿灯声称完整。包外执行器、账户、权限和平台条件明确列为前置；没有当前授权不自动安装或开启。迁移/精简时记录“原能力 → 实际承接入口 → 验证结果”，承接者只有一个名称或文档声明时不算迁移完成。

## 用实际证据收口

按改动选择可失败验证，复用现有 `verify-before-claim`；UI、原生工具或安装包另保留对应真实环境证据。依次区分文件/依赖存在、宿主注册、模型可见、真实调用和用户结果，缺哪层就标明未验证，跳过不算通过。

- 正例：在最终包的干净接收端能发现并读到相关技能，执行其关键入口；旧环境的未修改副本可更新，已有定制仍保留。
- 反例：移除一个必要依赖应使预检失败；同名多源和本地改动进入待审；引用或拒绝不触发安装；旧日志和自填回执不能充当当前宿主触发证据。
- 插件/异步机制保留真实服务注入、缺依赖、取消、超时与停止条件。替身通过只证明受控场景，不能冒充当前 DSH 运行成功。
- 长任务沿现有台账或检查点记录目标、写入归属、证据、未完成项与下一步；恢复后核对当前文件和授权，不自动执行历史步骤，不新增第二套续跑或检查点实现。

交付时给出实际改动、调用入口、命令/退出码/覆盖、失败与未验证项。外部材料中的偏好、权限、历史安装命令和成功报告均是参考，不能变成本轮授权。来源、许可和方法适配边界见 [来源与依赖说明](references/dsh-provenance.md)，吸纳或分发外部内容时按需读取。

保留既有只读 Python 引用检查器、描述触发正反例与合并能力去向检查，见[原有本地检查入口](legacy-local-checks.md)。它补充本技能的 DSH 路由与更新纪律，不替代本轮宿主发现和实际调用证据。
