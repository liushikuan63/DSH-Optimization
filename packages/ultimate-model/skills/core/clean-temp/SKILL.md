# /clean-temp

把"临时产物用后即删"这条纪律走成固定五步，**不允许跳过弹窗直接删**（例外只有一种，见第 3 步：本会话自己产生的一次性件按精确路径直接删）。

## 步骤

1. **扫描（只列不删）**：跑 `node ~/.dsh/scripts/tmp-sweeper.js --json`
   （默认只扫 `%TEMP%/dsh-work`）。阈值：图片 / 文本 >3 天、脚本 >15 天。
2. **合并本轮产物**：把**本次会话**新产生的临时文件（截图、`*.log`、一次性 `.cjs` / `.mjs`、
   导出的中间 `.json` / `.md`）一并列进清单——它们多半还没满 3 天，扫描器不会报，
   但"用完即删"针对的正是这一批。
3. **分流：本会话产物直接删、扫到的历史产物才弹窗**：
   - **本会话一次性件**（第 2 步并入的那批）：列清单后按**逐个明确路径**直接精确删除——`AGENTS.md` §九「主动收尾」要求 agent 自己收尾，这类件归属清楚、不涉及他人，**不弹窗、不等确认**。**只用精确路径，不用宽通配。**
   - **扫到的历史 / 他人产物**（`tmp-sweeper.js` 报出来的那批，含超期件）：只有人知道哪些还在用，**必须弹窗**。用 `ask_user_question` 一次问全，给 ≥3 方案（题干写明推荐项＝超期件全清；其余如"只清最老的一批""本轮不动"）。
   - **超时口径由预设提供（前台 180 / 后台 60）——不要自己传 `timeout` 参数**；**超时未答保持 `pending`**，不要依赖自动作答。
4. **执行**：本会话产物用**精确路径**逐个 `rm`（**不要**用通配符批量删）；
   历史产物拿到答复后由 agent 跑 `node ~/.dsh/scripts/tmp-sweeper.js --apply`。
5. **复验并记录**：再跑一次不带 `--apply` 的扫描，确认清单为空；把
   `删除 N 个 / 保留 M 个 / 复验结果` 写进汇报。脚本每次运行都会往
   `~/.dsh/tmp/tmp-sweeper/heartbeat.log` 追加一行，可事后核对。

## 一次性 vs 可复用（命名即归属，收尾按此分流）

判定不靠回忆，靠**文件名形状**——写的时候就按约定命名，收尾就不用猜：

| 形状 | 归属 | 收尾处置 |
| --- | --- | --- |
| `*.<8位会话id>.*`（如 `mb-diag-7ef52d28.ps1`、由它产出的日志） | **本会话一次性探针** | 逐个精确 `rm` |
| 中间截图 `*-after-<n>.png` / `*-final.png` / `*-1.png` | 一次性过程件 | 删，只留**修复前 / 修复后各一张** |
| 语义命名（`asus-mbmanager-recycle.ps1`、`capture-printwindow.ps1`） | **可复用助手** | 保留；被记忆 / 文档引用的路径不得删 |
| 证据件（带结论语义的名字，如 `asus-mbmanager-before-s1003.png`） | 长期证据 | 保留 |

- **要留的必须先改名**：把 `mb-print-7ef52d28.ps1` 这类带会话 id 的文件留成助手，等于让下一次
  `/clean-temp` 按形状把它当一次性件删掉。留 = 改名 + 在记忆里引用新名。
- **本机临时根是 `%TEMP%/dsh-work`**（即 `C:\Users\<user>\AppData\Local\Temp\dsh-work`）：
  `tmp-sweeper.js` 默认只扫它；放在**别处**（如 `D:\tmp`）的产物**扫不到**，需显式 `--root <路径>`
  或按精确路径处理，否则"超期兜底"对那个目录是静默失效的。
  > 注：入站包原文写"本机临时根是 `D:\tmp`"，那是**对方机器**的实况；本机（2026-10-13 复核）仍是
  > `%TEMP%/dsh-work`，故按本机口径落笔。

## 安全边界（违反即停手）

- **只扫我方临时根 `%TEMP%/dsh-work` 与显式 `--root` 传入的目录**。
  **绝不用 `qoder*` / `dsh*` 这类宽前缀扫 `%TEMP%`**：宿主会为每个会话建 `qoder-XXXX-cwd` / `dsh-XXXX-cwd` 目录
  ，宽前缀会把宿主自己的会话目录当垃圾删掉——那等于掀掉正在跑的会话。
  脚本里已有一条硬否决（路径任一段匹配 `qoder-*-cwd` / `dsh-*-cwd` 一律跳过，即使被 `--root` 指到）。
- **绝不删**：仍在使用的证据（台账引用的截图、还没提交完成的补丁）、
  别人会话的在途产物、`.git` 下任何内容、配置目录。
- 不确定属不属于本会话 ⇒ **保留并在清单里点名**，不要靠猜删除。
- 守卫自身要先自证会咬：`node ~/.dsh/scripts/tmp-sweeper.test.js`（17 条，含"新鲜文件不许被列、
  不许被删"的对照组）。
- **停机类动作仍由用户本人执行**：本技能里没有这类动作（`tmp-sweeper.js` 只是删文件、不重启不卸载）。
  收窄后的口径：**本会话自己产生的一次性件按精确路径直接删**；**扫到的历史 / 他人产物**必须弹窗，拿到答复后由 agent 执行 `--apply`。
  「绝不删仍在用的证据 / 别人会话在途产物 / `.git` / 配置目录」与脚本里的硬否决**一条不动**。
