# Exact runtime stability utility

The [bilingual utility guide](../runtime-stability-tool.md) is the single maintained command reference for preview, apply and restore, exact supported hashes, permanent backups, identity checks, exit codes and acceptance boundaries.

The utility targets reviewed DSH NEXT 2.0.20-next / core0.2.1-rc.3 bytes. It does not stop applications or make model requests. Unknown versions or local modifications return `REVIEW_UPDATE`.

The deployed revision90 and independently validated, undeployed revision13a are separate. Host shutdown ACK and official account403 remain unresolved. See [current acceptance](acceptance.md) and [runtime repairs](runtime-repairs.md).
